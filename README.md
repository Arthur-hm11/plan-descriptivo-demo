# Plan descriptivo — versión de demostración

Formulario para llenar el Plan descriptivo de un curso, con Guía de llenado, asistente "Pregúntale a la Guía" y hoja final para imprimir o guardar en PDF.

Es una versión de demostración: no guarda en la nube; lo que se llena se queda solo en el navegador de cada persona.
